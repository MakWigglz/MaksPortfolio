## Personal Finances App done with Python in two formats: one very efficient and simple in a single module, and another, purely for practice and for demonstrating my skills in using dependencies, libraries, and complex Python classes and methods, with SQL, Docker, numPy, matplotlib, Flask, and maybe Django...
# The Blueprint: 

HTML: The index.html file includes a form for user input (income and expenses) and a table to display the finance data.
Python Backend: The server.py script uses Python's built-in HTTP server capabilities to handle form submissions and save the data to a JSON file. It also serves the index.html file when accessed.
Server Execution: Run server.py to start the server. The application will be accessible at http://localhost:8000.
